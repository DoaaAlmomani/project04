# Project 04 - Personal Portfolio

## Description
A responsive personal portfolio website that presents my background as a
cybersecurity graduate: skills, projects, hobbies, and contact information.
It is built from scratch, without frameworks, templates, or UI libraries.

## Features
- Responsive layout built with Flexbox and CSS media queries.
- Light/Dark theme switcher: JavaScript changes the `data-theme` attribute on `<html>`, and CSS variables apply the new colors.
- Project cards that link to the related GitHub repositories.
- Contact form handled with JavaScript, without reloading the page.

## Technologies
HTML5, CSS3, JavaScript (ES6+), Git.

## Project Structure
- `index.html`: the structure of the page and all its sections.
- `style.css`: colors, layout, dark/light themes, and the responsive design.
- `script.js`: the theme switcher button and the contact form.
- `assets/`: the images used in the page (my profile photo).

## How to Run
Open `index.html` in any modern web browser. No installation is required.
